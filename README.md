# my-first-project
My first Git and GitHub practice project
I made this change from my Mac using Git.

Vocabulary:

| Word | Plain-English meaning |
|---|---|
| Repository (repo) | A project folder tracked by Git |
| Clone | Download a copy of a repository |
| README.md | The project's introductory document |
| .git | Hidden folder where Git stores project history and settings |
| Branch | A separate line of development |
| main | The primary branch in your project |
| Stage | Select changes for the next commit |
| Commit | Save a snapshot of selected changes |
| Push | Upload commits to GitHub |
| Origin | The nickname for your online GitHub repository |
| Remote | A repository stored somewhere else |
| Working tree | The current files in your project |
| Clean | No uncommitted changes |
| Diff | A comparison showing what changed |
